## 在做什么

- **让 AI 少读无用文件** —— 给编码 agent 配本地检索引擎，检索命中再读，而不是把整个文件塞进上下文
- **让回答有出处** —— 课程 RAG 工作台，回答必须标到讲义第几页，检索不到就明说不知道
- **让智能体真动手** —— 三维开放世界里，从「看懂画面」到「执行动作」的完整闭环
